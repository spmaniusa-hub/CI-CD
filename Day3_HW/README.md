## 🚀 Features & Architecture

1. **Dual Theme (Dark / Light)**: Glassmorphic dark mode default with seamless one-click switch to light mode and `localStorage` persistence.
2. **Pure Vanilla Web Tech**: Zero external framework dependencies; uses Semantic HTML5, CSS custom properties, and vanilla ES6+ JavaScript.
3. **Responsive & Mobile-Ready**: Fluid layout using CSS Grid and Flexbox, tested across desktop, tablet, and mobile viewport sizes.
4. **Interactive Disciplines Matrix**: Filterable domain pills allowing visitors to sort between Executive Operations, Cloud Systems, and Process Governance.
5. **Live Timezone Clock**: Dynamic real-time Pacific Time indicator reflecting local time in the San Francisco Bay Area.
6. **Accessible & SEO Optimized**: Open Graph tags, semantic heading hierarchy, high-contrast ratios, and keyboard accessible navigation.
